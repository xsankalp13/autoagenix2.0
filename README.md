# Autoagenix (autoagenix.com)

High-performance digital agency platform engineered with React, Tailwind CSS, and Framer Motion. Built inspired by the premium visual aesthetics of pytact.com.

## Domain & Contact
- **Domain:** `autoagenix.com`
- **Contact Email:** `hello@autoagenix.com`

## Core Services
1. **Custom Websites:** Bespoke, sub-second, conversion-focused web architecture built with modern frameworks.
2. **Workflow Automation:** Intelligent, autonomous 24/7 background automations connecting CRMs, webhooks, databases, and APIs.

## Tech Stack
- **Framework:** React 18 + Vite
- **Styling:** Tailwind CSS (Dark Obsidian `#050811` + Lime/Emerald Gradient Accents)
- **Animations:** Framer Motion (staggered hero, smooth scroll reveals, micro-interactions)
- **Icons:** Lucide React
- **Typography:** Plus Jakarta Sans & Inter

## Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle
npm run build

# Preview production build locally
npm run preview
```
